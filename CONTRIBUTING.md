# Contributing to Co-shop

1. Fork and clone, then `npm ci` and `npm run dev` (Next.js on http://localhost:3000).
2. Create a branch from `main`; keep each PR focused on one change.
3. Before pushing run `npm run lint` and `npx tsc --noEmit`.
4. Open a pull request using the template and link the issue it closes.

Commit messages follow [Conventional Commits](https://www.conventionalcommits.org/).
